# 口湖牽水䔲

以清道光二十五年（1845）農曆六月初七「六七水災」與雲林口湖「牽水䔲」祭典為題的 three.js 追思遊戲，單檔 PWA。

線上遊玩：https://kftseng2oo1.github.io/jun8/

## 三幕
- **序章・道光二十五年六月初七**：黃昏村落、暴風雨、海水倒灌，燈火一盞盞熄滅；天亮後來到萬善同歸塚。
- **第二幕・初七請水魂**：往上滑放出水燈，魂光隨燈光回到岸邊。
- **第三幕・初八牽䔲**：點選一座䔲、手指繞圈牽引（水獄 → 洗淨 → 天堂），最後倒䔲、燒䔲、功德圓滿。田中的䔲一律是傳統式：竹篾直筒三層、八根竹竿出頭掛米黃蝶紋三角旗、層間綠藍紫鋸齒彩紙、紙人與粉紅「萬善同歸」紙條，糊紙有粉紅、桃紅、素白、淡紫、橘紅。
  - **萬善祠與大水䔲**：重簷廟宇、兩側樓閣、石獅紅旗；廟旁常設一座彩繪大水䔲，會自動轉動、發光，點它或按「大䔲燈控」可調轉速、方向、亮度與燈色。
  - **挑飯擔祭祖靈**：萬善祠右側紅白帳棚，村民戴斗笠挑竹籃陸續擺上長桌；也可自己挑菜飯（最多 6 樣）挑擔走到祭壇，擺供、上香三拜。
  - **製作水䔲**：進入糊紙工坊，先選樣式——**傳統式**（竹篾直筒三層、八根竹竿出頭掛米黃蝶紋三角旗、層間鋸齒彩紙、紙人、粉紅「萬善同歸」紙條，可選粉紅花紙／桃紅／素白／紫紋／蝶紋／橘紅）或**彩繪塔式**；畫圓紮竹圈、滑動糊紙、選每層顏色花樣、裝屋頂彩布旗幡、寫敬獻者；完成後送入䔲陣，可牽引、倒䔲燒䔲。
  - **入廟參拜**：按「入廟參拜」或點廟，進入萬善祠廟內（紅柱楹聯、金雕神龕、神像、供桌）；可擺供品（鮮花、水果、餅乾、金紙、清茶、糖果、麵龜）、上香三拜、祈福；祈福時鐘鼓齊鳴，並依所求事項唸出祝文，也可點鐘或鼓自己敲響。
  - **道士化緣**：按「倒䔲・燒䔲」後，三位道士先出廟沿走道化緣，圓滿後才倒䔲。
  - **燒金紙**：「更多」裡的「燒金紙」或廟內「燒金紙」，打開金爐；可選大銀、小銀、經衣（給水魂更衣上岸）、刈金（萬善爺）。往上滑或輕點把金紙送進爐口，紙會飛入、燒出焦洞化成灰，有燒紙劈啪聲與手機震動（iPhone 需 iOS 18 以上）；每疊 50 張，可「整疊化」，累計張數、疊數、今日張數存在本機。
  - **貼紅紙・敬獻**：寫上敬獻者姓名（例：弟子曾崑福叩謝），貼在選定的䔲上層，鏡頭會特寫紅紙；點選有紅紙的䔲也會先特寫。
