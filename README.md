# 口湖牽水䔲

以清道光二十五年（1845）農曆六月初七「六七水災」與雲林口湖「牽水䔲」祭典為題的 three.js 追思遊戲，單檔 PWA。

線上遊玩：https://kftseng2oo1.github.io/jun8/

## 三幕
- **序章・道光二十五年六月初七**：黃昏村落、暴風雨、海水倒灌，燈火一盞盞熄滅；天亮後來到萬善同歸塚。
- **第二幕・初七請水魂**：往上滑放出水燈，魂光隨燈光回到岸邊。
- **第三幕・初八牽䔲**：點選一座䔲、手指繞圈牽引（水獄 → 洗淨 → 天堂），最後倒䔲、燒䔲、功德圓滿。
  - **貼紅紙・敬獻**：寫上敬獻者姓名（例：弟子曾崑福叩謝），貼在選定的䔲上層，鏡頭會特寫紅紙；點選有紅紙的䔲也會先特寫。

## 檔案
- `index.html`：遊戲本體（three.js 0.160，從 jsDelivr 載入）
- `manifest.webmanifest`、`sw.js`：PWA 安裝與離線快取
- `icons/`：圖示（`icon.svg` 為原稿）
